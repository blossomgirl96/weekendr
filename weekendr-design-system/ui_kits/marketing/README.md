# Weekendr — Marketing site UI kit

The public-facing weekendr.com — discovery, value prop, sign-up.

## Components
- `Header.jsx` — sticky cream header with logo, nav, sign-in
- `Hero.jsx` — big Fraunces headline, dual CTAs, sticker doodles
- `BrowseRail.jsx` — horizontal scroll rail of activity cards
- `ActivityCard.jsx` — the workhorse card
- `CategoryGrid.jsx` — 6 category tiles (parks, museums, etc.)
- `Testimonial.jsx` — quote with parent + kid name
- `CTABand.jsx` — sun-yellow band with closing CTA
- `Footer.jsx` — pine-green footer

## Run
Open `index.html`. Click the "Sign up" button to see the modal flow.
