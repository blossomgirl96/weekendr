# Weekendr — Planner app UI kit

The signed-in product. Browse, build a Saturday/Sunday plan, manage favorites and family.

## Components
- `Sidebar.jsx` — left nav (browse, this weekend, favorites, family, settings)
- `BrowseHeader.jsx` — top bar with location, date, search
- `FilterBar.jsx` — pill filters (outdoor, free, etc.)
- `ActivityList.jsx` — vertical list of activity rows
- `WeekendTray.jsx` — floating bottom-right tray showing Sat/Sun plan
- `FamilyChip.jsx` — sharing avatars
